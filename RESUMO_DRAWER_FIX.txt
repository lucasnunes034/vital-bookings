PROBLEMA:
--------
No iOS Safari, quando o teclado virtual aparece, o drawer era empurrado
incorretamente gerando espaços em branco e má experiência do usuário.

SOLUÇÃO APLICADA:
-----------------

1. ✅ UNIDADES DE VIEWPORT DINÂMICAS
   • Trocado 'vh' por 'dvh' (dynamic viewport height)
   • dvh se ajusta automaticamente ao teclado virtual
   
2. ✅ CSS ESPECÍFICO PARA iOS
   • Adicionado bloco @supports (-webkit-touch-callout: none)
   • Drawer fixado com position: fixed + bottom: 0
   • Body bloqueado quando drawer está aberto
   • Scroll suave com -webkit-overflow-scrolling: touch

3. ✅ LAYOUT FLEXBOX OTIMIZADO
   • DrawerContent: flex flex-col
   • Header: flex-shrink-0 (não encolhe)
   • Content: flex-1 min-h-0 (scroll correto)
   • Footer: flex-shrink-0 (fixo)

COMO USAR EM NOVOS DRAWERS:
---------------------------

<DrawerContent className="max-h-[92dvh] flex flex-col">
  <DrawerHeader className="flex-shrink-0">
    {/* Header fixo */}
  </DrawerHeader>
  
  <div className="overflow-y-auto flex-1 min-h-0">
    {/* Conteúdo scrollável */}
    <Input />
  </div>
  
  <div className="flex-shrink-0">
    {/* Footer fixo (opcional) */}
  </div>
</DrawerContent>
